# Web de desarrollo freelance

Web estática en español para presentar servicios de desarrollo y programación de videojuegos, Technical Art, shaders, VFX y desarrollo de software y herramientas.

[Ver la web en GitHub Pages](https://mikelarrizabalaga.github.io/Mikel-Game-Dev-Web/)

Abre `index.html` directamente o ejecuta `node dev-server.mjs` desde la carpeta del proyecto y visita [la vista local](http://127.0.0.1:4173). El servidor escucha únicamente en este equipo.

`index.html` contiene el contenido, `styles.css` define el diseño adaptable, `binary-background.js` repite el nombre en binario y `app.js` controla el selector de servicios y el resumen del encargo. El fondo está anclado a la ventana y el patrón se anima en bucle según la preferencia de movimiento del navegador. La web funciona sin dependencias ni recursos externos.

El resumen se prepara en el navegador. El botón de correo abre un borrador en la aplicación de correo del visitante.
