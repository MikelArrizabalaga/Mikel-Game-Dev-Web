Videojuegos y programación

            
Desarrollo videojuegos, prototipos jugables, mecánicas de gameplay y sistemas para proyectos en marcha. Trabajo con Unity y C#.

            

              
Ejemplo de encargo
Programar el movimiento, el salto y las colisiones de un personaje.

              
Entrega
Una mecánica jugable y el código preparado para integrarlo en tu proyecto.

            

            Preparar este encargo
          


          

            
Technical Art

            
Conecto el trabajo de arte y programación. Integro recursos en Unity y preparo flujos de trabajo para que el equipo pueda iterar con autonomía.

            

              
Ejemplo de encargo
Preparar un flujo para importar y configurar recursos de arte en el motor de juego.

              
Entrega
Recursos integrados y una guía para que el equipo pueda repetir el proceso.

            

            Preparar este encargo
          


          

            
Shaders

            
Programo shaders y materiales con parámetros que tu equipo puede ajustar. En Unity trabajo con Shader Graph y HLSL para URP.

            

              
Ejemplo de encargo
Crear un material de agua con controles de color, movimiento y transparencia.

              
Entrega
El shader integrado, un material de ejemplo y una explicación de sus parámetros.

            

            Preparar este encargo
          


          

            
VFX

            
Creo e integro efectos visuales en tiempo real para habilidades, impactos y elementos del entorno.

            

              
Ejemplo de encargo
Crear un efecto de impacto que indique al jugador que un golpe ha acertado.

              
Entrega
El efecto preparado para reutilizarlo en el juego y ajustarlo desde el motor.

            

            Preparar este encargo
          


          

            
Software y herramientas

            
Creo aplicaciones a medida y herramientas internas para simplificar tareas que tu equipo repite durante la producción.

            

              
Ejemplo de encargo
Crear una herramienta de editor para revisar recursos antes de importarlos.

              
Entrega
Una herramienta integrada y una guía breve de instalación y uso.

            

            Preparar este encargo
          

        

      

    


    

      

        
Cómo trabajo

        
Tendrás una primera versión para probar antes de cerrar la entrega.

      

      

        

          
Definimos el alcance

          
Acordamos qué debe resolver el encargo, qué recibirás y cómo lo integraremos con tu proyecto.

        

        

          
Probamos avances

          
Te paso una primera versión. Probamos juntos cómo funciona y uso tus comentarios para hacer los ajustes.

        

        

          
Preparo la entrega

          
Entrego el código o los recursos acordados, junto con las indicaciones para que tu equipo pueda integrarlos.
